# JetBrains highlighting

Use the **TextMate Bundles** plugin (bundled with recent IntelliJ IDEA / PyCharm).

1. **Settings → Editor → TextMate Bundles → +**
2. Select **`editors/jetbrains/intellij-textmate`** (this folder, not a `.tmbundle` zip).

If the file picker refuses paths under Google Drive, copy this repo (or just `editors/jetbrains/intellij-textmate`) to a local disk and import from there.

Grammars are copied from `editors/vscode/syntaxes/`; they track the same `import … as` and `.clrsa` directives as VS Code.
