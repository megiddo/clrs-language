# clrs-language

Yak shave to implement CLRS pseudocode as a language.

Run a driver over the example modules:

```bash
python3 -m clrs run examples/insertion-sort.clrs -- 'A ← [5, 2, 4, 6, 1, 3]; InsertionSort(A); A'
```
